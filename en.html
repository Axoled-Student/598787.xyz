Welcome to Axo Mail

Building practical tools around Gmail.

Axo Mail is an independent project for people who manage their own Gmail accounts. Our existing work is NTU Gmail Sync, a personal synchronization utility. Next, we want to test whether Claude can help summarize long conversations, find relevant messages, and prepare replies for people to review.

01 / About

Small in scope.
Clear in purpose.

Axo Mail focuses on a simple problem: managing and understanding email can take too much time.

Our approach is straightforward: start with a concrete problem, build something useful, document what it does, and improve it over time.

We are developing for individual Gmail users who want to handle their own data and spend less time searching long threads. NTU Gmail Sync is the existing utility; Axo Mail is the wider direction for further email tools. AI-assisted functions remain research plans, not live features.

02 / Projects

What we're working on

We distinguish the utility we have already documented from the features we plan to test.

Featured project / 01

NTU Gmail Sync

Existing project

NTU Gmail Sync is a personal utility intended to let a user authorize their own Google account and perform Gmail synchronization for their requested workflow.

The utility is designed around user authorization with Google OAuth. This public website explains its purpose and links to data-handling policies; this website itself does not connect to Gmail. The name NTU Gmail Sync refers to this specific existing utility under the broader Axo Mail project direction.

03 / Development

Current direction

We plan to test whether Claude can turn selected, user-authorized email content into something immediately useful. These are research topics, not available product features.

01

Conversation summaries

Given a conversation a user selects, Claude could generate a concise summary and identify follow-up items.

Research
02

Natural-language search

With authorized message context, Claude could help answer a user's question and point them to relevant messages.

Research
03

Reply assistance

Using a selected thread and user instructions, Claude could draft a reply for review. The user would decide whether to send it.

Research

Proposed workflow — not implemented

  1. 1. User selectsA person authorizes access and chooses the messages or conversation they want help with.
  2. 2. Claude processesThe proposed integration would send only the relevant authorized content and the user’s request to Claude for analysis.
  3. 3. User reviewsA summary, cited answer, or draft comes back for review. The user stays in control of any reply.
About data and AI

The Axo Mail website does not process Gmail messages or send email data to Claude. Before building or launching an integration, we will evaluate Google API Limited Use requirements, data protection, access controls, user consent, and retention policies. Nothing here claims a working Claude integration today.

04 / Information

Frequently asked questions

Basic information about the project and how it is being developed.

Who maintains Axo Mail?

Axo Mail is an independently developed early-stage project. Its existing NTU Gmail Sync utility is documented here. The public website repository and contact channel are on GitHub.

Can I use Claude-powered email features today?

No. Claude-powered features are an area of development and research. This site does not offer a live AI inbox or a production Claude integration.

Does this website access my Gmail account?

No. This is a public information website. NTU Gmail Sync is a separate utility; any Gmail authorization must be initiated by the user through Google's OAuth process.

Is the project affiliated with Google, NTU, or Anthropic?

No. Axo Mail and NTU Gmail Sync are independent projects and are not official services of Google, National Taiwan University, or Anthropic.
