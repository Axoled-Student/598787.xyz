Axo Mail｜電子郵件工具專案

讓 Gmail 同步與郵件整理，更簡單、更省時。

Axo Mail 是獨立開發的電子郵件工具專案。現有工作是以 Google OAuth 授權為基礎的 NTU Gmail Sync；下一階段將研究如何透過 Claude 協助使用者理解郵件、找到重要資訊，以及準備回覆草稿。AI 功能目前尚未上線。

01 / 關於專案

從實際需求出發，
把工具一步步做好。

Axo Mail 關注的問題很單純：同步、搜尋與理解電子郵件，不應該花掉太多時間。

本專案以日常使用 Gmail 的個人使用者為對象，從特定的同步需求開始，逐步探索更好用的郵件工具。

目前的既有工作是 NTU Gmail Sync。後續的 Claude 郵件摘要、自然語言搜尋與回覆輔助仍屬研究規劃；我們會清楚區分現有工具與尚未推出的功能。

02 / 現有專案

目前正在做的事

從既有的 Gmail 同步工具開始，公開說明它的用途、授權方式與資料處理原則。

現有專案 / 01

NTU Gmail Sync

既有專案

NTU Gmail Sync 是個人開發的 Gmail 同步工具，讓使用者透過 Google OAuth 授權自己的 Google 帳號，並依所需功能進行郵件資料同步。

這個網站提供公開的專案說明，以及隱私權政策和服務條款。網站本身不會要求登入 Google 帳號，也不會直接讀取訪客的 Gmail 內容。

NTU Gmail Sync 是目前的具體開發成果；Axo Mail 則是延伸電子郵件工具的整體專案方向。

03 / 開發規劃

研究 Claude 可以如何協助處理郵件

以下是下一階段想測試的功能，尚未正式實作或對外開放。我們希望先確認準確性、實用性與使用者授權流程，再決定如何推出。

01

長篇郵件摘要

由使用者選取往來郵件後，規劃讓 Claude 整理討論重點、待辦事項與重要資訊。

研究中
02

自然語言搜尋

規劃使用已授權的相關郵件內容，協助回答使用者的問題，並指出答案涉及哪些郵件。

研究中
03

回覆草稿輔助

以使用者選擇的郵件及指示產生回覆建議，內容需由使用者確認後才能決定是否寄出。

研究中

規劃中的處理流程｜尚未實作

  1. 1. 使用者選擇內容先完成必要授權，再指定要摘要、搜尋或回覆的郵件與需求。
  2. 2. Claude 協助處理未來的整合預計將與該需求相關、且獲得授權的內容提供給 Claude 分析。
  3. 3. 使用者檢查結果產生摘要、查詢答案或草稿供使用者確認；是否寄出回覆由使用者決定。
資料安全與使用者同意

本網站不會讀取 Gmail 郵件，也不會把郵件資料傳送給 Claude。日後若實作 AI 功能，會先評估 Google API 使用者資料政策、必要的授權與告知方式、存取控制，以及資料保存與刪除機制，並在正式上線前更新相關說明。

04 / 常見問題

你可能想了解的事

關於專案用途、開發進度及資料權限的基本說明。

Axo Mail 與 NTU Gmail Sync 有什麼關係？

NTU Gmail Sync 是既有的個人 Gmail 同步工具；Axo Mail 是延伸郵件整理及 AI 輔助功能的整體專案方向。網站中的開發規劃不代表相關功能已上線。

目前可以使用 Claude 的郵件功能嗎？

還不行。Claude 郵件摘要、自然語言搜尋與回覆草稿都屬於規劃中的研究項目，目前沒有對外提供 AI 收件匣服務。

瀏覽這個網站會讀取我的 Gmail 嗎？

不會。這是公開的資訊網站，不需要 Google 登入。NTU Gmail Sync 的帳號存取則需由使用者自行透過 Google OAuth 授權。

誰在開發 Axo Mail？

Axo Mail 是獨立開發、仍在早期階段的軟體專案。可透過公開的 GitHub 儲存庫查看網站內容或提出問題。

這是 Google、臺灣大學或 Anthropic 的官方服務嗎？

不是。Axo Mail 與 NTU Gmail Sync 都是獨立專案，並非 Google、國立臺灣大學或 Anthropic 的官方服務。
