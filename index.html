NTU Gmail Sync

NTU Gmail Sync is a personal utility that allows a user to sign in with their own Google account and synchronize Gmail data for the user's requested workflow.

What the application does

  • Uses Google OAuth so users can securely sign in with their own Google account.
  • Requests only the Google permissions needed for the Gmail synchronization features selected by the user.
  • Uses authorized Gmail data only to provide the synchronization functionality requested by the signed-in user.

Access

This information page is publicly available and does not require a login. Google sign-in is required only when a user chooses to use the application's Gmail synchronization functionality.

Data and privacy

Details about the Google user data the application may access, how that data is used, stored, shared, and deleted are described in the Privacy Policy.
